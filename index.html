Why use matrices?

Complex circuits produce multiple equations. Matrices organize them into one compact system:

A · X = B
01 · Model

Apply Kirchhoff’s Voltage Law (KVL) or Current Law (KCL).

02 · Organize

Arrange coefficients, unknown currents or voltages, and known sources.

03 · Solve

Use Cramer’s Rule, Gaussian elimination or matrix inversion.

METHOD 1 · KVL

Mesh analysis

KVL — Kirchhoff’s Voltage Law: the algebraic sum of voltage rises and drops around a closed loop is zero. Choose clockwise mesh currents and form a resistance matrix.

Two-loop worked example

RESISTANCE MATRIX EQUATION

[R] [I] = [V]

[ 6  -4 ] [ I₁ ] = [ 10 ]
[-4  10 ] [ I₂ ]   [  0 ]

Loop current I₁ 2.2727 A

Loop current I₂ 0.9091 A

Shared branch current 1.3636 A

How the equations are formed

  1. Assign clockwise currents I₁ and I₂.
  2. Loop 1: (R₁ + Rₛ)I₁ − RₛI₂ = Vₛ.
  3. Loop 2: −RₛI₁ + (Rₛ + R₂)I₂ = 0.
  4. Place the coefficients in the resistance matrix. Diagonal entries are total loop resistances; off-diagonal entries are negative shared resistances.
METHOD 2 · KCL

Nodal analysis

KCL — Kirchhoff’s Current Law: total current entering a junction equals total current leaving it.

How it works

  1. Choose a reference node (ground = 0 V).
  2. Assign voltage variables to the other nodes.
  3. Use Ohm’s Law to express branch currents using node voltages.
  4. Apply KCL at each non-reference node.
  5. Arrange the equations as [G][V] = [I] and solve for node voltages.

Conductance matrix [G]

[G] · [V] = [I]

Diagonal entries: sum of conductances connected to that node.

Off-diagonal entries: negative conductance connecting two nodes directly.

Conductance G = 1/R and is measured in siemens (S).

Interpretation

For mesh analysis, the unknowns are loop currents. For nodal analysis, the unknowns are node voltages. The meaning and units depend on the circuit model used to build A and B.

SOLUTION TECHNIQUES

Three matrix methods

The same linear system can be solved using different mathematical techniques.

Cramer’s Rule

Uses determinants. Replace one column of A with B to calculate each unknown.

xᵢ = det(Aᵢ) / det(A)

Convenient for small systems such as 2×2 and 3×3.

Gaussian elimination

Uses elementary row operations on the augmented matrix [A | B] to create an upper-triangular system, then back-substitutes.

Matrix inversion

If A is invertible, multiply both sides by its inverse.

X = A⁻¹B
Determinant and uniqueness

If det(A) ≠ 0, the square system has a unique solution. If det(A) = 0, A is singular and there is no unique solution.

REAL-WORLD CONNECTIONS

Where are matrix methods used?

These methods scale from classroom resistor networks to complex engineering systems.

Power grids

Matrix equations support analysis of voltages and power distribution across interconnected buses.

SPICE circuit simulation

Circuit simulators use matrix-based numerical methods to solve circuit equations.

Microchips and VLSI

Electrical models help analyze voltage drops and interconnections in integrated circuits.

Sensors and bridge circuits

Matrix equations help analyze resistor networks such as Wheatstone bridges.

Further topic in your presentation

AC circuits use impedance Z = R + j(XL − XC), giving a complex matrix equation [Z][I] = [V]. This prototype introduces that concept but does not yet calculate AC phasors.
